## Method notes worth carrying into the skill

1. **Move the corpse and CI tests into the SLICE BUILDER, before the language/licence call.** Across the three screens, Req 6 and Req 7 killed roughly 15 of 22 C++ finalists and 8 of 21 Rust/Go/TS finalists, and `pushed_at` was the liar every time — a release or side branch moves it while the default branch is frozen. One GraphQL call fetches `defaultBranchRef.target.history(first:40)` for 20 repos at once. Filter on default-branch commit dates with non-chore subjects, not on `pushed_at`.
2. **Add an AI-mark column to the slice** (`CLAUDE.md` / `AGENTS.md` / `.agents` / `.coderabbit.yaml` / `GEMINI.md` at root, one contents call). It killed universal, bpftime, gem5, ecal, parsedmarc, baybe, siliconcompiler and wemake-python-styleguide this session.
3. **A maintainer's numbered EPIC needs its own pre-clone gate.** greenmask cost the most because #392 is invisible to every title search and every commit query — it lives in an issue BODY as checkboxes. `gh api "search/issues?q=repo:R+in:title+epic+OR+roadmap"` plus one body read, run right after the lane is named, would have killed it in two calls instead of a clone and a full source audit.
4. **Company-mirror repos with squashed release-dump histories** (reindexer) make Stage 2c's commit-subject histogram return noise. Use the changelog as the lane-density instrument and say so.
5. **C++ at >= 500 stars is the wrong band for this work** and `size:>5000` makes it worse — it selects for asset-heavy renderers. If more C++ is wanted, slice on BUILD SYSTEM (CMake with a vendored `third_party/` and no `find_package` of a heavy dep) and drop the size floor.
