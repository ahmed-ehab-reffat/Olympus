## Method notes worth keeping

1. **⭐ A repo's OWN earlier major version is prior art, and `gh api contents?ref=<old-tag>` finds it
   for one call.** The "ports inherit the parent's feature list" law (pandapower/MATPOWER) has a
   same-repo form: a v2 -> v3 REWRITE inherits its own v2 feature list. OpenPNM v3's percolation
   module looked gloriously empty on every `grep` for imbibition / snap-off / cooperative filling,
   and `openpnm/algorithms/MixedInvasionPercolation.py` has been sitting at tag `v2.8.2` at 36 KB
   the whole time. **Add to the Stage 3b absorption block: list the repo's tags, and if a major
   version boundary is visible, check the previous major for your capability BEFORE sketching LOC.**
2. **⭐ MAINTAINER-SIDE AI SWEEPING is now a lane-death signal in its own right, and it has a
   fingerprint.** techan's `codex/*` branch family was recorded as a one-off; this session found the
   same behaviour under four different marks — `app/copilot-swe-agent` as a commit author
   (go-workflows, Pynite), `Checkpoint before follow-up message` commits (ikpy), and an explicit
   AI-workflow doc plus a "papercut" sweep programme (neva). A maintainer running an agent over
   their own tracker closes the surgical-correctness gap class continuously, which is precisely the
   f2p surface. **Grep the commit stream for `copilot|codex|Checkpoint before|papercut|AI-assisted`
   at Stage 2c**, and treat a hit like a `fix/<topic>-*` branch family.
3. **⭐ The competitor swarm has reached the FRESH domains.** The 2026-09-06 lesson was that three
   PYTHON SCIENTIFIC pool repos were swarmed. This session found `binggao1230` on structural
   engineering (Pynite) and a six-PR-in-three-days account on a Rust spreadsheet parser (calamine),
   and `MaxFreedomPollard` linking ytt to Apache datasketches. Picking an untouched DOMAIN no longer
   buys distance from the swarm; only an untouched CAPABILITY does.
4. **The moved-path artefact bit again, this time inside our own skill text.** `olympus-hunt`'s
   Stage 0-bis pool table records neva as "desugarer 0, irgen 0, typesystem 0, interp 0". Re-running
   it gives 50 / 41 / hot / path-does-not-exist. A heat number recorded in our own docs decays the
   same way a tracker probe does — re-measure, never inherit.
5. **Requirement 7 stays the cheapest gate** (dyon and OpenSubdiv died on "no CI runs at all" for one
   call each), and `NOASSERTION` remains a reliable early filter — it flagged openmc, OpenSubdiv,
   gtsam and gonum before any deeper work.
