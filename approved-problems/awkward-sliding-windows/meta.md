# Add sliding windows over the lists of an array

Add `ak.windows(array, size, *, stride=1, incomplete="drop", align="left", axis=-1, highlevel=True, behavior=None, attrs=None)` and `ak.unwindows(array, *, stride=1, axis=-2, highlevel=True, behavior=None, attrs=None)`.

A window is `size` adjacent elements of one list, and consecutive windows begin `stride` elements apart. Both are integers of at least one, a boolean not counting as one: something that is not an integer is a `TypeError`, and a smaller one, or a value outside the choices named below, a `ValueError`. `axis` counts as it does everywhere else, negative values included, and a depth the array does not have, or one a union's branches disagree about, is an `AxisError`; at the outermost depth the array itself is the list windowed.

`ak.windows` gives the array one more dimension: every list at `axis` becomes the list of its windows, ordered by where they begin, and everything outside `axis` is left alone. With `align="left"` the windows are laid out from the start of the list, the first one beginning at its first element; with `align="right"` they are laid out from its end, the last one ending after its last element. `incomplete` says what becomes of a window that reaches past the list. `"drop"` keeps only the windows lying entirely inside it. `"keep"` also keeps those holding at least one of its elements, cut off at its edge. `"pad"` keeps the same windows as `"keep"` but fills them out to `size` with missing values, after a left aligned window's elements and before a right aligned one's. So a list shorter than `size` gives no window at all under `"drop"`, and an empty list gives none under any of the three. Windows that all hold exactly `size` elements are fixed size lists, cut off ones are variable length, and the dimension holding the windows is fixed size when the dimension it came from was fixed size and variable when that one was variable, whatever lengths its lists happened to have. Whatever parameters the windowed lists carried, a string tag among them, belong to the windows now, and the dimension holding the windows carries none; at the outermost depth there is no list to take them from, so the windows made there carry none either. A string cannot hold missing characters, so padding gives up that tag, and its characters give up theirs with it.

For `ak.unwindows`, `axis` names the dimension holding the windows, the lists inside it are the windows, and the result has one dimension fewer. Window number `j` of a list sits `j` strides along it and contributes only the elements the window before it did not reach. Every element some window contributes is in the rebuilt list, in position order, and nothing else is: a stride wider than the window before it leaves a gap that nothing fills, and no later window takes an element back. So laying the kept windows of a left aligned pass back over one another with that same stride, of at most `size`, returns the lists `ak.windows` was given. The windows' own parameters become the rebuilt lists'. Anything but lists inside `axis` is a `ValueError`.

A missing list has no windows and stays missing, either way, and neither operation changes the array it was given. A named axis keeps its name, so the dimension `ak.windows` inserts is unnamed and `ak.unwindows` drops the name of the one it takes away. Both operations work on lists reached through an index, a mask, a union or a record, and on typetracer arrays, where the data is unknown, so no value may be looked at. `highlevel`, `behavior` and `attrs` work as they do throughout the library, so metadata follows the result, an explicit one wins, a low level result carries none, and an array that intercepts calls for itself decides what comes back. `size`, `stride` and `axis` take any integer, numpy's own included, and `axis` also a name the array carries. A bytestring behaves like a string throughout.

The result's type never depends on the data, so it comes out the same whether the values are known or not, and an array with no lists at all still types the same way. A window reaching no further than the one before it contributes nothing, never less than nothing, so the rebuilt list never loses an element it already held. The named axes that survive keep the dimensions they described.
