# Add stream-processing elements to Amaranth's standard-library streams

Add stream-processing components to `amaranth.lib.stream`. Every component preserves its data exactly; no `valid`/`ready` timing causes unintended loss, duplication, or reordering.

Each component exposes `i_stream` and `o_stream`; where there are several it uses `i_streams`/`o_streams` arrays. Constructors take the payload shape (or a bit width) then any `factor`/`count`, and raise `ValueError` for a non-positive bit width, `factor`, or `count`, or for a `WidthDownConverter`/`WidthUpConverter` `width` that is not a multiple of `factor`.

`WidthDownConverter(width, factor)` splits a `width`-bit input into `factor` outputs of `width // factor` bits, least-significant part first. `WidthUpConverter(width, factor)` packs `factor` inputs of `width // factor` bits into one `width`-bit output, least-significant first, holding an incomplete trailing group rather than emitting it. `Gearbox(i_width, o_width)` repacks the input bit stream, least-significant word and bit first, into `o_width`-bit words for widths that need not divide, emitting only complete words. Each of the three transfers once per cycle on its narrower side (the `WidthDownConverter` output, the `WidthUpConverter` input, the narrower `Gearbox` side) under a moving stream, adding no idle cycle beyond an initial fill.

`FramedGearbox(i_width, o_width)` converts a packet-framed stream between widths. Its input payload is a struct `{data: i_width, last: 1}`, where `last` marks a packet's final word; its output is `{data: o_width, last: 1, valid}`. Within a packet the concatenated input bits (least-significant word first, least-significant bit first) are repacked into `o_width`-bit output words; every word but the packet's last has `valid == o_width`, and the final word has `last` set with `valid` equal to the remaining 1 to `o_width` bits. One packet's bits never share an output word with another: the partial final word is flushed at the boundary and the next packet starts fresh. Like the converters it holds full throughput on its narrower side under a moving stream, so a packet boundary adds no idle cycle there beyond the initial fill, even when a packet's final word is still draining as the next packet begins.

`SkidBuffer(shape)` forwards payloads unchanged, driving output `payload`/`valid` and input `ready` from registers yet still transferring once per cycle. `Arbiter(shape, count)` merges `count` inputs by work-conserving round robin, starving no ready input and preserving each input's order. `Demux(shape, count)` is a combinational router forwarding the input to the single output chosen by `select` and taking backpressure only from it. `Fork(shape, count)` delivers each input payload to every output, advancing only once all have accepted it. `Join(shape, count)` takes one payload from every input and emits their concatenation, the first input in the least-significant bits.
