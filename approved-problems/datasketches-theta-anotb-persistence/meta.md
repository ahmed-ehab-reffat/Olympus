Title: Persist stateful Theta A-not-B operations

Make stateful `ThetaAnotB` operations persistable through the same public lifecycle as the other stateful Theta set operations. Support construction in caller-provided `MemorySegment` storage through both the family-based builder and a `buildANotB(MemorySegment)` convenience overload, expose state serialization and typed `ThetaAnotB.wrap` factories, and include A-not-B in generic `ThetaSetOperation.heapify` and `wrap` dispatch. `ThetaSetOperation` must expose the public static sizing helper `int getMaxAnotBResultBytes(int k)` for caller-provided A-not-B storage.

Serialization and restoration must preserve virgin, empty, exact, and estimation-mode state, including zero-retained nonempty estimation state and the configured seed. A heapified operation must be independent of its source memory. A wrapped operation must remain backed by the supplied resource, report that relationship through the existing memory-status API, and keep its backing image synchronized after `setA`, every `notB`, and a resetting `getResult`. On a writable direct-backed operation, `setA(null)` must first reset and persist an empty, zero-retained state and then throw `SketchesArgumentException`; any view wrapping the same resource must observe that reset immediately after the call fails. Direct state that outgrows the supplied storage must be rejected without changing the prior state.

Restored operations must produce the same public results as uninterrupted execution, accept further `notB` inputs, support interim `getResult(false)`, reset and return the final result through `getResult(true)`, and remain reusable for a later independent operation. Stateless `aNotB` calls remain independent of persisted state. A read-only wrapped operation must allow nonmutating result, serialization, and stateless calls while rejecting calls that mutate state.

Follow the established Theta set-operation serialization conventions and reject an image with the wrong family, serialization version, seed hash, inconsistent state, or insufficient bytes. The precise internal state representation is not prescribed.
