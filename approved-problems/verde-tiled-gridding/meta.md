# Add tiled gridding with tapered blending to the interpolators

`tile_regions(region, shape=None, spacing=None, overlap=0.0, adjust="spacing")` divides a region into equal tiles, as `[W, E, S, N]` lists ordered by south edge, then west edge. `shape` is the tile count as (north, east); `spacing`, one value or a (north, east) pair, is their size, and the count along a direction is the region size divided by it, rounded up. With `adjust="region"` tiles keep that spacing and the region grows equally on both sides of each direction; `adjust` does nothing when `shape` is given. Every tile is then extended by `overlap` times its own size on each edge shared with a neighbour, never on a region boundary. Both or neither of shape and spacing, a non-positive spacing, a shape below one, an unknown `adjust`, and an overlap below zero or of one or more are errors.

`taper_weights(coordinates, tile, margin, region=None)` weighs points inside a tile. Along each direction the factor rises linearly from zero at a shared edge to one at distance `margin`, one value or a (north, east) pair, taking the smaller factor when both edges are shared; a margin of zero or less means no taper there. Multiply the two direction factors. Points outside the tile weigh zero; edges on `region`'s boundary are not tapered.

`TiledGridder(estimator, shape=None, spacing=None, overlap=0.25, min_data=10, max_data=None, max_depth=3, region=None, blend="taper")` is a `BaseGridder` that fits an independent copy of `estimator` per tile, leaving the given one untouched. It tiles `region`, or the data's bounds, with `tile_regions`. Given `max_data`, a tile holding more points splits into four equal tiles, recursively, until it holds no more or has split `max_depth` times, counting points before extension. Tiles are then extended; one whose extended bounds hold fewer than `min_data` points is skipped, an error if none remain. Each estimator sees only the points its tile holds, edges included, with their data weights.

With `blend="taper"`, `predict` averages the predictions of the tiles containing the point, weighted by their taper weights, each tile's margin being twice its own extension. With `blend="nearest"` it takes the prediction of the containing tile whose centre is closest, ties going to the earlier tile; other values are errors. Points no fitted tile contains are NaN; data of several components predict a tuple. Store extended tiles in `tiles_`, fitted copies or None in `estimators_`, region in `region_`. `tile_report()` returns a `pandas.DataFrame`, a row per tile in that order, columns "west", "east", "south", "north", "n_data" (points its extended bounds hold), and the boolean "fitted".

`merge_grids(grids)` merges `xarray.DataArray` grids sharing dimensions and lattice, coordinates rising by the same spacing, an error otherwise or when none given. The result spans every coordinate any grid covers, keeping the first grid's name and dimensions. A grid weighs by `taper_weights` over its own bounds against the merged bounds, margin half its size each direction; missing values weigh zero. Points take that weighted average, the plain average of available values when all weigh zero, and NaN where no value is available.
