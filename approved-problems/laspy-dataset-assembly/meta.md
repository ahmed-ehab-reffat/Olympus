# Add dataset assembly operations to laspy

Add a `laspy.assembly` module, re-exported at top level: `merge_datasets`, `partition`, `crop`, `thin`, `split_by`, `summarize`, `Partition` and `DatasetSummary`. A `Partition` carries `key` as `(level, column, row)`, `bounds` as the cell extent in a `laspy.Bounds`, `core_count` and `data`. A `DatasetSummary` carries `point_count`, `bounds` as a `laspy.Bounds` or None, `counts_by_classification` and `counts_by_return` as dicts by value, `gps_time_span` as earliest and latest, `extra_dimension_names` and `density`, all reachable unchanged through `as_dict()`.

Membership uses stored coordinates, not floats. World values become stored as `round((value - offset) / scale)`, halves to even. World sizes convert the same way; `cell_size`, `buffer` and `spacing` take one value or one per axis; `scales` and `offsets` three. Sources are never modified. Results keep source scaling, records and input order, and recompute header point count, bounds and per return counts. `LaspyException` rejects no datasets, a sub unit size, a negative distance or count, a `max_points` under one, a bad bound count, world bounds that do not increase, an unknown `keep` or dimension name, and a wrong axis count.

`merge_datasets(datasets, *, scales=None, offsets=None, point_format_id=None, file_version=None)` concatenates in order. The point format defaults to the largest input id, the version to the largest, raised when needed; a forbidden one is an error. Scales default to the finest input, offsets to the smallest coordinate present, else the first's. Points are requantized; one outside signed 32 bit range is an error.

Dimensions copy by name: source-only names are dropped, target-only names read zero. Extra dimensions union with their first definitions in appearance order; one name with two types or scalings is an error. Variable length records, extended or not, are the first dataset's plus later unseen user id and record id pairs, counted per section; the extra bytes record is rebuilt. Extended records survive only from version 1.4. Datasets carrying GPS time must agree on week versus standard time, which the result keeps.

`partition(data, *, cell_size, origin=(0, 0), buffer=0, min_points=1, max_points=None)` returns a list of partitions sorted by key. Cells own their lower edge. An over budget cell splits into quadrants while both stored sizes are even. A `buffer` grows the cell by that distance on each axis, keeping its half open shape; gained points follow the core, marked synthetic, and core flags stay. `min_points` counts core points only.

`crop(data, bounds)` keeps points with `lower <= stored < upper` for four or six bounds, minima then maxima; a box that quantizes to nothing selects nothing. `thin(data, spacing, *, keep="first")` keeps one point per voxel anchored on the stored origin: a voxel's `first`, `last`, `lowest`, `highest`, or `centre`, nearest the voxel centre by squared stored distance, ties to the earliest. `split_by(data, dimension)` groups by dimension value, ascending keys. `summarize(data)` counts the points themselves, not the header; density is points per bounding box area. The span is None without GPS time, and the density is None when the area is zero; an empty dataset summarizes to zero with no bounds, span or density, keeping its names.
