Title: Materialize mmCIF biological assemblies

Add `Bio.PDB.build_biological_assembly(structure, mmcif_dict, assembly_id)`. The source is a Biopython `Structure` whose chain IDs are mmCIF label-asym IDs, as produced by `MMCIFParser(auth_chains=False)`, and `mmcif_dict` is an ordinary `MMCIF2Dict`-shaped mapping. Return a new `Structure` containing the requested biological assembly without modifying either input.

Use every `_pdbx_struct_assembly_gen` row whose assembly ID equals the string form of `assembly_id`. For each row, select exactly the comma-separated label-asym chains it names and expand its operator expression. Support bare or parenthesized operator IDs, comma lists, inclusive ascending numeric ranges, and Cartesian products of any number of adjacent parenthesized groups. Operator IDs may be numeric or character codes. Apply Cartesian-product groups from right to left as defined by PDBx/mmCIF, so the leftmost matrix is the outermost affine transform.

Materialize every resulting row, operator-sequence, and selected-chain occurrence in every source model. Preserve the structure ID and header, model IDs and serial numbers, and hierarchy metadata including `xtra` dictionaries, residue data, atom data, occupancies, and altlocs. All alternatives in disordered atoms and disordered residues must be copied and transformed, while retaining the selected alternative. Every output chain within a model must have a deterministic, collision-free string ID, and corresponding expansions should receive the same IDs in models with the same selected chains. The exact ID spelling is not prescribed. The output header mapping, all generated chains, residues, atoms, coordinate arrays, and all `xtra` dictionaries must be independent of the source and of sibling generated copies.

Raise `ValueError` instead of returning a partial assembly when the requested assembly has no generation row; a required category column is missing, empty, non-sequential, or has a different row count from its peers; an expression or asym-ID list is malformed; an inclusive range descends; operator IDs are duplicated or referenced but absent; a selected asym ID is absent from any source model; the source has no models; or a matrix/vector component is not a finite number. Validation failures must leave both inputs unchanged. Error wording and the internal parser, copy, provenance, matrix, and chain-ID allocation strategies are not prescribed.
