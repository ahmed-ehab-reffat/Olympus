# Behavioral levels

Status: **historical only; problem closed for plagiarism/similarity**

1. Provider discovery and ordinary 8-bit uncompressed output.
2. Correct header, planar channel order, and bottom-up row orientation.
3. Standard source region, asymmetric subsampling and offsets, band order, and raster input.
4. One through four channels and unsigned 8/16-bit uncompressed interoperability.
5. RLE tables, packet grammar, 127-sample boundaries, and one/two-byte atoms.
6. Complete 16-bit RLE write/read interoperability without regressing existing reader behavior.

These levels describe diagnostic clusters, not partial acceptance thresholds.
